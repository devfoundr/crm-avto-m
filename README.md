# CRM кузовного автосервиса «Авто-М»

Кликабельный прототип CRM для кузовного ремонта. Один файл `index.html`, без сборки и без сервера — открывается в браузере и показывает полный рабочий сценарий приёмщика.

**Демо:** https://devfoundr.github.io/crm-avto-m/

## Задача

У кузовного сервиса машина проходит длинную цепочку: приёмка с описанием повреждений, расчёт, согласование со страховой или клиентом, разборка, жестянка, покраска, сборка, выдача. Универсальные CRM этого не умеют — там сделка либо открыта, либо закрыта, а между ними ничего.

Прототип сделан, чтобы показать заказчику логику до начала разработки: как выглядит карточка машины, какие статусы нужны, что видит приёмщик и что мастер.

## Что показывает

- Приём автомобиля: клиент, машина, описание повреждений
- Этапы ремонта со статусами и переходами между ними
- Заказ-наряды с работами и запчастями
- Список машин в работе с фильтрами по статусу

## Зачем прототип

Прототип на HTML дешевле спора по ТЗ. Заказчик кликает и говорит «вот здесь не так» до того, как написана первая строчка бэкенда. По итогам такого макета уточняется состав статусов, набор полей и права ролей — и разработка идёт уже по согласованной логике.
